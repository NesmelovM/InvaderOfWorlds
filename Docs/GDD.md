# Invader of Worlds — дизайн-документ

Версия 0.4 · 28.10.2026 · зафиксированы решения по смерти, оружию, стенам и боссу

## 1. Концепция

Рогалик, в котором забег — это не подземелье, а **маленькая планета**. Хаб — крыша башни магов. Игрок случайно телепортируется на планету, прорывается через поселения монстров и либо погибает, либо уходит через портал, унося силу.

**Elevator pitch:** «Hades встречает Mario Galaxy — рогалик, где каждый забег это маленький мир, который можно обойти пешком за пару минут, а на нём деревни, которые надо вычистить».

## 2. Столпы

1. **Планета как арена.** Мир замкнут, у него нет края карты, горизонт загибается вверх.
2. **Один забег — одна планета.** Один вход, один выход.
3. **Поселения, а не коридоры.** Противник живёт группами у строений.
4. **Возврат через босса.** Портал выхода охраняет босс со стражей.
5. **Смерть не обнуляет всё.** Добыча конвертируется в мета-прогресс.

## 3. Цикл

```
Хаб (башня магов) → портал → Планета
    ▲                            │
    │                            ├── смерть → экран итогов ──► хаб (−70% добычи)
    └────────────────────────────┴── портал выхода (босс) ──► хаб (+бонус)
```

## 4. Хаб — экран подготовки

Не прогулка, а меню: статичная камера смотрит на башню, курсор свободен.

| Элемент | Назначение | Состояние |
|---|---|---|
| Магазин: урон / здоровье / скорость | 5 уровней каждого | готово |
| Визуальный рост башни | кристаллы, золото, высота | готово |
| Портал | старт забега | готово |
| Дерево прокачки | трата опыта | не начато |
| Оружейная | выбор оружия в 6 слотов | не начато |

## 5. Планета

- **Радиус:** 80–100 м (в тестовой сцене 90).
- **Гравитация** к центру, «верх» — нормаль поверхности.
- **Камера:** из-за плеча, с параллельным переносом ориентации.
- **Точка входа:** одна, случайная. **Выход:** портал, максимально далеко от входа.
- **Генерация:** один шар + расстановка точек по seed.
- **Рельеф:** высота грунта берётся лучом, учитываются уклон и ступени.

## 6. Бой

**Оружие игрока — 6 слотов, как в Vampire Survivors.** Игрок не целится: каждое оружие само бьёт по ближайшему врагу в своём радиусе, со своей перезарядкой. Управление сводится к позиции — что и нужно на маленькой сфере.

| Тип оружия | Поведение |
|---|---|
| Ближний бой | замах сферой перед героем |
| Снаряд | летит в ближайшую цель |
| Взрыв | задевает всех вокруг героя |

Стартовый набор: удар вблизи (34 урона, 0.5 с) и снаряд (18 урона, 1.1 с).

**Враги:**

| Тип | Поведение |
|---|---|
| Мечник | преследует, замахивается с телеграфом, бьёт в упор |
| Лучник | держит 7–12 м, стреляет только при прямой видимости |
| Элита ближнего боя | 180 HP, тяжёлый удар |
| Элита дальнего боя | усиленный лучник — в работе |

**Босс — один тип на MVP.** Три слота умений, как у игрока: ближняя атака, дальний залп, усиление. Стоит у портала выхода со стражей.

**Укрепления — разрушаемые.** Стены поселений имеют здоровье и разваливаются от урона.

## 7. Прогрессия

**Внутри забега:** золото и опыт с врагов, сила растёт.

**При смерти — теряется 70% добычи** и происходит возврат в хаб.

**При уходе через портал — вся добыча плюс бонус за чистый заход.**

**Мета:** золото тратится в магазине хаба (урон, здоровье, скорость), опыт — в дереве прокачки (не начато). Прогресс сохраняется в JSON.

## 8. Технические решения

| Решение | Значение | Причина |
|---|---|---|
| Unity | 6000.6.7f1 | актуальная, проект перенесён с 2021.3.11f1 |
| Render pipeline | Built-in | все ассеты сделаны под него |
| Движение | аналитическое по сфере | `CharacterController` выбивал персонажа физикой |
| Камера | собственный риг | Cinemachine FreeLook не работает на сфере |
| Ввод | Legacy Input Manager | изолирован в двух местах |
| Интерфейс | GUI без Canvas | прототип, позже заменим на uGUI + TMP |
| Сохранение | JSON в `persistentDataPath` | золото, опыт, уровни |

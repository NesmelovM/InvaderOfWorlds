# Invader of Worlds — дизайн-документ

Версия 0.3 · 28.10.2026 · решения автора от 28.10 зафиксированы

## 1. Концепция

Рогалик, в котором забег — это не подземелье, а **маленькая планета**. Хаб — крыша башни магов на родной планете. Из хаба игрок случайно телепортируется на планету, прорывается через поселения монстров и либо погибает, либо уходит через портал, унося силу.

**Elevator pitch:** «Hades встречает Mario Galaxy — рогалик, где каждый забег это маленький мир, который можно обойти пешком за пару минут, а на нём — деревни, которые надо вычистить».

## 2. Столпы дизайна

1. **Планета как арена.** Мир замкнут, у него нет края карты, горизонт загибается вверх. Враг может прийти с любой стороны.
2. **Один забег — одна планета.** Один вход, один выход, всё происходит между ними.
3. **Поселения, а не коридоры.** Противник живёт группами у строений и укреплений — бой идёт за территорию, а не за комнату.
4. **Возврат через босса.** Портал выхода охраняет сильный противник со стражей: уйти можно только прорвавшись.
5. **Смерть не обнуляет всё.** Опыт и золото конвертируются в прогресс хаба.

## 3. Основной цикл

```
Хаб (башня магов)
   │  вход в портал → случайная точка на поверхности
   ▼
Планета: поселения (3-20 монстров) + укрепления
   │
   ├── прорыв к порталу выхода → бой с боссом и стражей → уход (+опыт, +золото)
   └── смерть → опыт и золото конвертируются в прогресс (детали в п.7)
```

Один забег: 10–20 минут. Сессия: 2–4 забега.

## 4. Хаб — крыша башни магов

Точка между забегами. Заготовки уже есть: `Assets/Prefabs/UI/PlayerHome.prefab` и кнопки в `MainMenu.unity` — **«Дерево прокачки»**, **«Магазин»**, **«Оружейная»**.

| Элемент | Назначение | Состояние |
|---|---|---|
| Круг телепорта | старт забега, случайная планета | не реализовано |
| Дерево прокачки | постоянные улучшения за опыт | только кнопка UI |
| Магазин | расходники и снаряжение за золото | только кнопка UI |
| Оружейная | выбор оружия и заклинаний | только кнопка UI |

Визуально: ночное небо, каменная башня, магический круг, родная планета на фоне. Камера свободно вращается вокруг площадки.

## 5. Планета

- **Радиус: 80–100 м.** Обход по экватору — около 3 минут бега, но до портала путь короче.
- **Гравитация** к центру сферы, «верх» игрока и камеры — нормаль поверхности.
- **Камера: из-за плеча.** Выбор обоснован тем, что бой не только ближний: заклинания и стрельба требуют прицеливания и обзора вперёд.
- **Точка входа:** одна, случайная на поверхности.
- **Точка выхода:** одна, портал, максимально удалённый от входа.
- **Генерация (MVP):** один сферический меш + расстановка точек на поверхности (поселения, портал, вход). Детерминированно по seed — забег воспроизводим для отладки.

## 6. Поселения и бой

**Поселение** — 3–20 монстров, живущих у строений. Вокруг — оборонительные сооружения: частокол, стены, башни, ловушки. Задача игрока — прорваться через них, а не обойти: портал находится за территорией.

| Параметр | Значение MVP |
|---|---|
| Поселений на планете | 3–6 |
| Монстров в поселении | 3–20 |
| Радиус поселения | ~14 м |
| Радиус укреплений | ~26 м |
| Типы врагов | ближний бой, дальний бой, элита |

**Бой** — групповой. Враги держат позиции у строений, реагируют на шум боя, дальние занимают высоты (башни, стены). Игрок использует:
- ближний бой — основная механика;
- оружие дальнего боя — для снятия стрелков на высотах;
- заклинания — контроль толпы и урон по площади.

**Босс у портала** — сильный одиночный противник плюс стража. Победа над ним открывает уход с планеты.

## 7. Прогрессия и экономика

**Внутри забега:** с врагов падают **опыт** и **золото**. Опыт внутри забега повышает силу персонажа и агрессивность врагов, золото — валюта хаба.

**После забега:** и при смерти, и при успешном уходе опыт и золото конвертируются в прогресс:

| Ресурс | Куда идёт |
|---|---|
| Опыт | узлы дерева прокачки |
| Золото | магазин, снаряжение, расходники |

**Штраф за смерть — открытый вопрос.** Пока считаем, что при смерти конвертация идёт с потерей доли (обсуждается 30–50%). Успешный уход через портал — конвертация полностью и, возможно, с бонусом за риск.

## 8. Технические решения

| Решение | Значение | Комментарий |
|---|---|---|
| Unity | последняя (Unity 6) | проект 2021.3.11f1 переедет, см. `MIGRATION-UNITY6.md` |
| Render pipeline | Built-in | все ассеты сделаны под него |
| Камера | собственный риг | Cinemachine FreeLook не работает на сфере |
| Движение | CharacterController | предсказуемо на малых планетах, без дрожи Rigidbody |
| Ввод | Legacy Input Manager (`Both`) | ввод изолирован в двух местах, легко заменить |
| Ассеты | LowPolyAlienWorld, polyperfect Low Poly Ultimate Pack | хватает на прототип |

## 9. Что реализовано в коде

| Файл | Назначение |
|---|---|
| `Assets/Scripts/Planet/Planet.cs` | сфера: центр, радиус, нормаль, случайная точка, угловое расстояние |
| `Assets/Scripts/Planet/PlanetContentGenerator.cs` | расстановка входа, поселений и портала по seed |
| `Assets/Scripts/Player/PlayerMotor.cs` | движение по сфере, прыжок, прижатие к поверхности |
| `Assets/Scripts/Player/PlayerCameraRig.cs` | камера из-за плеча с верхом от нормали планеты |

## 10. Открытые вопросы

1. **Штраф за смерть:** 30%, 50% или вся конвертация только при успешном уходе?
2. **Заклинания:** сколько слотов в MVP и есть ли мана/кулдауны?
3. **Укрепления:** нужны ли разрушаемые стены в MVP или достаточно статичных препятствий?
4. **Босс:** один тип на все планеты в MVP или сразу несколько?

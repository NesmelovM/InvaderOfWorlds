# Invader of Worlds — дизайн-документ

Версия 0.1 · 28.10.2026 · восстановлен по описанию автора и остаткам проекта

## 1. Концепция

Рогалик, в котором забег — это не подземелье, а **маленькая планета**. Хаб — крыша башни магов на родной планете. Из хаба игрок случайно телепортируется на планету, проходит её как обычный рогалик и либо погибает, либо возвращается через портал, унося с собой набранную силу.

**Elevator pitch:** «Hades встречает Mario Galaxy — рогалик, где каждый забег это маленький мир, который можно обойти пешком за пару минут».

## 2. Столпы дизайна

1. **Планета как арена.** Мир замкнут, у него нет края карты, горизонт загибается вверх. Враг может прийти с любой стороны.
2. **Один забег — одна планета.** Никаких этажей и переходов: телепорт внутрь, всё происходит здесь, телепорт наружу.
3. **Смерть не обнуляет всё.** Часть силы сохраняется и превращается в мета-прогресс — иначе повторные забеги бессмысленны.
4. **Возврат — это решение.** Портал открывается не сразу: игрок сам выбирает, уходить с добычей или дожать планету ради большего риска.

## 3. Основной цикл

```
Хаб (башня магов)
   │  активация круга телепорта
   ▼
Планета  ── 3-5 энкаунтеров ──► портал возврата ──► Хаб (+сила)
   │                                                   ▲
   └──────────── смерть ───────────────────────────────┘
                (частичная потеря)
```

Один забег: 5–10 минут. Сессия: 3–5 забегов.

## 4. Хаб — крыша башни магов

Точка между забегами. В проекте уже есть заготовка UI `Assets/Prefabs/UI/PlayerHome.prefab` и кнопки в `MainMenu.unity`: **«Дерево прокачки»**, **«Магазин»**, **«Оружейная»**.

| Элемент | Назначение | Состояние |
|---|---|---|
| Круг телепорта | старт забега, случайная планета | не реализовано |
| Дерево прокачки | постоянные улучшения за силу | только кнопка UI |
| Магазин | расходники, снаряжение на забег | только кнопка UI |
| Оружейная | выбор оружия | только кнопка UI |

Визуально: ночное небо, башня из камня, магический круг, вокруг — родная планета как фон. Камера свободно вращается вокруг площадки.

## 5. Планета

- **Масштаб:** радиус 40–80 м. Полный обход по экватору — 40–60 секунд бега.
- **Гравитация:** направлена к центру сферы; «верх» игрока — нормаль поверхности.
- **Камера:** третье лицо, up-вектор плавно следует за нормалью.
- **Наполнение:** 3–6 точек интереса, разбросанных по поверхности: лагерь врагов, сундук, алтарь, элитный враг, портал.
- **Генерация (MVP):** один сферический меш + процедурная расстановка точек интереса по сфере (равномерно, с минимальной дистанцией).
- **Генерация (позже):** сборка поверхности из кусков-префабов, биомы, вода.

## 6. Бой

- Игрок: ближний бой (основное), позже — дальний/магия.
- Враги: ближний бой, дальний бой, элита — классы уже заведены в коде (`EnemyMelee`, `EnemyRange`, `EnemyElite`).
- Скалирование: параметры врага растут от «стоимости в силе мира» по формуле `1.2^cost` (сохраняем замысел из `Enemy.cs`, но переносим в данные, а не в конструктор).

## 7. Прогрессия

**Внутри забега:** сила растёт с каждого убитого врага и подобранного предмета. Сила — и валюта, и уровень опасности: чем сильнее игрок, тем злее враги на следующей планете.

**Мета:** при возврате сила конвертируется в постоянные узлы дерева прокачки. При смерти — теряется доля (например, 50%), что делает смерть болезненной, но не разрушительной.

## 8. Технические решения

| Решение | Значение | Комментарий |
|---|---|---|
| Unity | 2021.3.11f1 | версия из `ProjectVersion.txt`, менять пока не будем |
| Render pipeline | Built-in | URP в `manifest.json` нет |
| Камера | Cinemachine 2.8.9 | FreeLook для сферы не годится, нужен свой риг |
| Ввод | Legacy Input Manager | `Input.GetAxis`, новый Input System не подключён |
| UI | uGUI + TextMesh Pro 3.0.6 | |
| Ассеты | LowPolyAlienWorld, polyperfect Low Poly Ultimate Pack | хватает на прототип |

## 9. Открытые вопросы

1. **Камера:** из-за плеча или сверху-сзади? От этого зависит управление на сфере.
2. **Масштаб:** планета радиусом 40 м (камерная, уютная) или 80 м (есть где бродить)?
3. **Бой в MVP:** только ближний, или сразу ближний + один дальний враг?
4. **Смерть:** теряется 50% силы, вся сила, или сила сохраняется, а теряется только лут?
5. **Генерация:** шар + расстановка точек (быстро) или сборка из кусков поверхности (дороже, но красивее)?

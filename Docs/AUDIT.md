## Архитектура: что задумано

Слои уже намечены правильно:

```
Assets/Scripts/
├─ Component/Markers    — маркеры расстановки (игрок, враги) для редактора
├─ Component/Spawners   — SpawnerEnemy, спавн волн
├─ Data                 — LevelData (ScriptableObject), EnemySpawnerData
├─ Editor               — LevelDataEditor, сбор данных уровня со сцены
├─ Infrastructure       — GameFactory, интерфейсы, InputService
├─ Persons              — Player, Enemy (Melee / Range / Elite)
└─ Physics              — GravityAttractor, GravityBody (гравитация к сфере)
```

Идея «собрать данные уровня кнопкой Collect в редакторе» — рабочая и полезная, её сохраняем.

## Что работает как задумано

| Файл | Оценка |
|---|---|
| `Physics/GravityAttractor.cs` | Классическая гравитация к сфере, рабочая. Притягивает и разворачивает тело по нормали |
| `Physics/GravityBody.cs` | Рабочая обёртка: отключает `useGravity`, каждый `FixedUpdate` тянет к аттрактору |
| `Component/Markers/*` | Пустые маркеры — нормальный приём для расстановки через редактор |
| `Editor/LevelDataEditor.cs` | Собирает позиции маркеров в `LevelData` |
| `Data/LevelData.cs` | Card-данные уровня: старт игрока, спавнеры, параметры волн |

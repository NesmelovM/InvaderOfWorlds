# План работ

Принцип: сначала **вертикальный срез** — одна планета, несколько врагов, полный цикл «забег → смерть/возврат → хаб». Контент и красота — после того, как цикл играбелен.

## M0. Окружение — готово

- [x] Unity Hub и Unity **6000.6.7f1** (взяли актуальную, вместо 2021.3.11f1)
- [x] Personal-лицензия активирована
- [x] Проект перенесён на Unity 6: ассеты с `.meta`, старые сцены и скрипты удалены
- [x] git подключён к `github.com/NesmelovM/InvaderOfWorlds`, GitHub Desktop для визуальной работы с ветками
- [x] Проект компилируется без ошибок

## M1. Планета, движение, камера — готово

- [x] `Planet`: центр, радиус, нормаль, случайная точка поверхности
- [x] Движение по сфере аналитически, без `CharacterController` (он выбивал персонажа физикой)
- [x] Учёт рельефа: высота грунта лучом, уклон, ступени, обрывы
- [x] Камера из-за плеча с параллельным переносом ориентации
- [x] Препятствия: `SphereCast` со скольжением
- [x] Проверка на полюсах и через экватор — пройдено

## M2. Бой (в работе)

- [x] `Health` + `IDamageable`: урон, смерть, события для UI
- [x] `PlayerAttack`: замах сферой перед персонажем, кулдаун
- [x] `EnemyBrain`: преследование по поверхности, удар в упор
- [x] `SettlementSpawner`: заселение поселений из `PlanetContentGenerator`
- [x] Тестовая сцена: два врага рядом с точкой появления
- [ ] Полоска здоровья игрока и врагов
- [ ] Отдача и замах (визуальная обратная связь)
- [ ] Разные типы врагов: дальний бой, элита
- [ ] Реакция на урон: вспышка, отступление

**Готово, когда:** игрок убивает трёх врагов, враги убивают игрока, оба умирают корректно.

## M3. Цикл забега

- [ ] Машина состояний: `Hub → Loading → Planet → Death/Return → Hub`
- [ ] Генерация планеты: сфера + расстановка точек интереса (энкаунтеры, сундук, портал)
- [ ] Портал возврата: активируется после N зачищенных энкаунтеров
- [ ] Сила: начисление за убийства, конвертация в мета-валюту
- [ ] Экран смерти и экран возврата
- [ ] Сохранение мета-прогресса (JSON в `Application.persistentDataPath`)

**Готово, когда:** полный цикл проходится без перезапуска редактора, прогресс сохраняется между запусками.

## M4. Хаб и мета

- [ ] Сцена хаба: крыша башни, круг телепорта
- [ ] Дерево прокачки (5–7 узлов), магазин, оружейная — на существующих UI-заготовках
- [ ] Стартовое оружие и его влияние на бой
- [ ] Звук: удары, смерть, телепорт

**Готово, когда:** есть смысл возвращаться в хаб и тратить силу.

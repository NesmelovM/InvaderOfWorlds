# План работ

Принцип: сначала **вертикальный срез** — одна планета, один враг, полный цикл «забег → смерть/возврат → хаб». Контент и красота — после того, как цикл играбелен.

## M0. Окружение (полдня)

- [ ] Установить Unity Hub и Unity **2021.3.11f1** (точная версия проекта, без апгрейда)
- [ ] Войти в Unity-аккаунт, активировать Personal-лицензию
- [ ] Открыть проект из `InvaderOfWorlds/`, дождаться импорта (первый импорт 10–20 минут)
- [ ] Установить git, подключить `origin` → `github.com/NesmelovM/InvaderOfWorlds`
- [ ] Убедиться, что проект компилируется, зафиксировать базовый коммит

**Готово, когда:** проект открывается, консоль без ошибок компиляции, сцена `Level1` запускается.

## M1. Планета, движение, камера (ядро ощущения игры)

- [ ] `PlanetGravity`: гравитация к центру, разворот тела по нормали (переписать `GravityAttractor`/`GravityBody`)
- [ ] `PlanetWalker`: движение по касательной к сфере, прыжок, ограничение скорости
- [ ] Камера третьего лица с плавным up-вектором от нормали (свой риг вместо FreeLook)
- [ ] Отладочная планета-сфера радиусом 50 м с текстурой-сеткой
- [ ] Проверка на «полюсах»: нет инверсии управления, нет застреваний

**Готово, когда:** можно обойти планету по кругу, камера не крутится, персонаж не проваливается и не вибрирует.

## M2. Бой (минимум)

- [ ] `Health` как компонент, урон, смерть, i-frames
- [ ] Атака игрока: замах, хитбокс, отдача
- [ ] Враг ближнего боя: преследование по поверхности, атака, смерть
- [ ] Спавн волн через `SpawnerEnemy` (починить пути `Resources.Load`)
- [ ] Полоска здоровья игрока и врага

**Готово, когда:** игрок убивает трёх врагов, враги убивают игрока, оба умирают корректно.

## M3. Цикл забега

- [ ] Машина состояний: `Hub → Loading → Planet → Death/Return → Hub`
- [ ] Генерация планеты: сфера + расстановка точек интереса (энкаунтеры, сундук, портал)
- [ ] Портал возврата: активируется после N зачищенных энкаунтеров
- [ ] Сила: начисление за убийства, конвертация в мета-валюту
- [ ] Экран смерти и экран возврата
- [ ] Сохранение мета-прогресса (JSON в `Application.persistentDataPath`)

**Готово, когда:** полный цикл проходится без перезапуска редактора, прогресс сохраняется между запусками.

## M4. Хаб и мета

- [ ] Сцена хаба: крыша башни, круг телепорта
- [ ] Дерево прокачки (5–7 узлов), магазин, оружейная — на существующих UI-заготовках
- [ ] Стартовое оружие и его влияние на бой
- [ ] Звук: удары, смерть, телепорт

**Готово, когда:** есть смысл возвращаться в хаб и тратить силу.

## M5. Содержимое и сборка

- [ ] 3–4 типа планет (разные биомы из имеющихся паков)
- [ ] 3 типа врагов + элита
- [ ] Баланс силы и наград
- [ ] Билд под Windows, проверка на чистой машине

## Порядок, если время ограничено

M0 → M1 → M2 → M3. Это уже играбельный цикл. M4 и M5 — после того, как в M3 захочется играть ещё раз.

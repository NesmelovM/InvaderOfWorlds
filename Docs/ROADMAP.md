## Ближайшие три шага

1. **Портал выхода с боссом.** Босс у портала, стража, условие открытия, экран победы. Замыкает цикл.
2. **Дерево прокачки в хабе.** Трата опыта, узлы вместо трёх линий.
3. **Модели и звук.** Заменить капсулы ассетами из `LowPolyAlienWorld`, добавить удары и телепорт.

## Технический долг

- Диагностика движения (`_logMovement` в `PlayerMotor`) включена по умолчанию — выключить перед сборкой
- Персонажи и предметы — примитивы, материалов из паков не используем
- Ввод: legacy Input Manager (`Active Input Handling = Old`), при переходе на новый Input System понадобится адаптер в двух местах
- `PlanetSurface.SampleGroundRadius` дублирует расчёт из `PlayerMotor` — свести в один метод
- Нет тестов и автосборки
